# DX12 — M1.3 validated locally

Le chemin DX12 privé de `graphics/` est validé localement en Windows x64 pour
Device, Queue, Swapchain, Acquire, Submit, Present, synchronisation,
Resize/Recreate et le deuxième frame. Aucun shader, resource binding ou type
natif public n'est fourni. Aucun support DX12 Linux annoncé.

M1.4 ne modifie pas ce périmètre ; les ressources et commandes restent M2.
