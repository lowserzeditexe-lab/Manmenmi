# Vulkan — not validated in M1.4

Le runtime système Vulkan a été observé, mais le SDK de développement manque
dans l'environnement courant et le backend Vulkan Mamenmi n'est pas validé.
Vulkan reste une référence initiale de correction, **pas** le modèle de l'API
publique. Version minimale/extensions UNKNOWN. Aucun shader Vulkan n'est fourni.
